# LumaNest 界面约定

LumaNest 使用同一个发行程序。开发者日常使用的实例与公开安装使用相同页面、播放器及后台模块；媒体地址、账号、来源、缓存目录和个人偏好属于各自的私人配置，不通过维护另一套程序实现差异。

本文件约束后续界面修改；实际安装与验证结果见 [发行验证](release-report.md)，设计约定不能代替真实截图和操作检查。

## 文字与排布

- 基础背景为 `#12151b`，面板为 `#1c2129`，正文为 `#f4f1ea`，次级文字为 `#a6afb9`。海报页可以使用图片提取的背景色，但按钮、字体和间距仍遵循同一组规则。
- 优先使用本机 Segoe UI Variable、Microsoft YaHei UI。普通正文和表单标签为 15–16px，行高至少 1.5；帮助文字保留清晰层级，不用过小字号把大量内容塞进一屏。
- 布局以 8px 为基本间距，常用 16、24、32px。桌面表单的标签、说明、输入分别对齐；窄屏改为单列，长路径与名称换行，不能推出横向滚动条。
- 常规控件高 40–44px、圆角 12px；主按钮使用暖白底和 22px 胶囊圆角。圆角与边框低对比，不以鲜蓝描边表示鼠标悬停。
- 键盘焦点必须清晰可见，并保留合理的 Tab 顺序。不要为去掉鼠标边框而同时删除键盘焦点。
- 图标使用本地矢量资源，大小与笔画一致。图标、评分数字、年份和其他文字按同一行的视觉中心对齐。

## 影院页面

- 首页、详情、搜索结果与选集共用按钮、卡片和导航样式。相同操作不随页面变化为另一套尺寸或边框。
- 优先选择真实高分辨率横版背景，画面铺满可见区域；没有合适横版时才对现有图进行合理裁切。已经适合横向铺满的图片，不额外强制加两侧模糊柱。
- 裁切要尽可能保留主要人物，避免只露半个头或默认把人物藏到画面外。按源图宽高比和主体位置计算，不能针对所有海报套一个偏移值。
- 本地主体检测使用默认安装的 OpenCV Headless、NumPy，以及随包的动漫模型和 OpenCV 实拍人脸模型。发布自检必须实际加载两个模型并执行检测，不能把缺少检测器的居中回退当成完整功能通过。
- 渐变从图片颜色自然过渡到页面背景，保证文字可读。切换图片时不能出现拼接横条、画面突然位移或短暂空白。
- 清晰竖版封面、横版背景和标题标志各有用途，不能仅因其他客户端在不同画幅使用另一张图，就判定本客户端图片错误并自动替换。
- 从作品详情点击“返回”应保留此前首页推荐和浏览位置；刷新推荐是独立动作，不与所有返回操作绑定。
- 在显示前准备所需图片并保留上一帧可用内容。减少动画设置必须生效，不能用大量动画掩盖加载问题。
- 剧集封面有可靠来源时使用；没有时保持选集网格整齐，不伪造图片。评分与人物图片缺失状态要明确，同一人物的多项职务合并展示。

## 设置与状态

- 设置页按同一配置 schema 渲染，不把某台电脑的路径、账号或偏好写进页面代码。
- 控件说明作用范围、继承关系和生效时机。保存配置、应用运行环境、启动服务是不同动作，状态不能混用。
- 未实现的选项禁用并说明原因；接口失败、未授权和资料暂无分别显示。不能用美化后的“成功”状态隐藏实际失败。
- 凭据只输入与替换，不读回显示。公开截图使用空白临时实例或纯测试数据。
- 每次调整至少检查实际浏览器的桌面与 390px 布局、保存操作、弹窗和键盘焦点；影院原生页面需另做真实播放器检查。
