# 规则与用户可选策略

这是持续维护的规则清单，具体可用字段以设置页为准。部分高级接口仍在规划中，当前完成状态见 [实施记录](implementation-ledger.md)。固定的数据正确性规则不能通过开关禁用。

## 5. 以前提出的规则如何产品化

| 原有要求 | 交给用户选择的部分 | 系统必须始终保证的部分 |
|---|---|---|
| 改名后资源库、工作台和缓存跟着改 | 命名模板、使用用户名称还是资料名称、是否允许云端改名 | 用稳定对象身份关联；旧任务不能把新名改回去；改显示名不重复下载 |
| 同系列电影放一起 | 合集目录/虚拟合集、中文名优先、合集例外 | 用已确认关系归类，不能凭相似标题把无关作品放一起 |
| 新目录建好后清掉旧空目录 | 不清理/确认空后回收；保留期限 | 移动成功→绑定与索引更新→重新列目录确认空→回收；扫描失败不等于目录为空 |
| 铃芽之旅重复、虚构99季 | 正传/特别篇/季号/绝对集数映射，人工修正 | 同一源对象不重复入库；未知季号进入待确认队列，不假装真实第99季 |
| 主题曲MKV跟着电影 | 主片、主题曲、花絮、预告、其他附加视频的分类规则 | 附加视频挂在主片详情，不因无法匹配独立电影阻塞主片 |
| 想手动指定作品/百科 | 搜索候选、粘贴支持的条目URL、输入提供方ID、手动编辑和锁定 | 年份、类型、季号和ID分清；参考链接不自动等于整套资料都有可信解析 |
| 每个新作品补评分、每季单独评分 | 显示的平台、来源优先级、更新间隔、缺失时隐藏/提示 | 季分不能复制整剧分；量纲、投票、来源和时间保留；未知来源不冒充平台 |
| 学习评分图标 | 平台显示顺序、紧凑/完整显示 | 图标与来源对应、对齐一致；不可把一个数字贴到多种图标后 |
| 高清海报、铺满、尽量无字横图 | 图源顺序、语言、最低质量预设、无文字横幅偏好、单片换图 | 身份正确优先；不把小图放大冒充高清，不拿其他季的图凑数 |
| 人物不被裁头、画面不偏右 | 单片焦点/缩放/拖动复位、全局铺满策略 | 原图主体位置与显示裁切区分别判断；切图前后容器位置稳定 |
| 奥德赛不同端海报不必强制一致 | 每个展示场景的图片选择 | 不新增“所有客户端横竖图必须相同”规则；该要求已被用户撤回 |
| 缺人物图片要补 | 提供方顺序、追加可信资料来源、隐藏无图人物/暂无照片 | 来源身份核对；明确无图可完成任务；网络故障不能直接宣告永久无图 |
| 同一人导演和编剧合并 | 职务显示顺序、人数上限 | 同人一卡合并职务，优先稳定人物ID，不仅按名字合并同名者 |
| 每片真实媒体参数、换源后更新 | 详情字段、探测时机、超时/读取预算 | 按源版本指纹失效；显示实际码率/分辨率/轨道/HDR，不继承旧源参数 |
| 返回首页保留刚刚的推荐 | 明确首页按钮是否换一批、刷新间隔、手动换一批 | 详情返回恢复原推荐、选中项和滚动位置；取消“每次返回必刷新”旧规则 |
| 切换不卡顿，提前缓存海报 | 邻近预取数量、图片预算、减少动画 | 新图解码前保留旧画面；避免空白一秒和旧UI闪现；跨页面共用组件 |
| 不要蓝色悬停边框 | 焦点风格、高对比模式、动画强度 | 鼠标悬停与键盘焦点区分；去掉蓝框不等于去掉可访问焦点 |
| 字号、按钮、评分整齐 | 字号/密度/缩放的整体预设 | 共用尺寸、基线、间距和图标规范，不能逐页随意偏移 |
| 单集有图更好，没图也要整齐 | 真实单集图开关、缓存预算 | 没图用整齐无图布局；不重复用整剧海报冒充单集画面 |
| HDR直接转SDR，亮度可拖动 | 默认输出模式、临时SDR按钮、画面滑条、单片记忆 | 显示当前实际输出；不支持的HDR参数说明限制，数值变化不能是空操作 |
| 看影片时不要后台抢带宽 | 暂停离线任务/限速，前读预算，恢复等待时间 | 当前播放优先；暂停仍属播放会话；顺序缓冲从当前读取位置前进 |
| 10G空间在E盘做播放缓冲 | 路径、容量、预缓冲目标、最大前读距离 | 已完成区段可立即被播放复用；换源不串用旧字节；没有完整下载也可命中 |
| 收藏与追剧触发缓存 | 收藏自动下、预取集数、近期时间窗、计量网络限制 | 手动取消后不立即被自动任务重新加入；特别篇不串入正传预取 |
| 缓存名跟着作品改 | 可读文件名模板、迁移到新路径 | 显示名不作为唯一标识；播放中不移动正在读的文件；缓存清理不删云端原件 |
| 工作台别永远红着或运行中 | 重试上限、完成归档、缺项可接受策略 | 提供真实终态与动作；接受无图不等于假造成功；已知缺项保留记录 |
| 自动化按我选的方式运行 | 手动、定时、启动时；新增/全库/选中范围 | 批次幂等、重启恢复、可取消；不能因切换设置启动未选择的全库任务 |
| 校园网优先，外出正常网络 | 网卡/网络环境绑定、回退策略、按流量类别配置 | 直连意图覆盖解析、重定向、图片和子进程；失败不私自切到VPN |
| 手机平板用VidHub | Jellyfin访问地址、远程接入方式、用户可见库 | 服务端数据与第三方客户端私有UI分清；不声称能远程控制VidHub所有排版和功能 |

“删除罕见人物”建议默认解释为隐藏该人物卡片，不删除原始演职人员资料。云端删除、版本替换和本地缓存清理是不同权限，不能共享一个危险的“自动清理”开关。
