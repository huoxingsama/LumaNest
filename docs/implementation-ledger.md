## 已知限制

1. 测试以临时实例、模拟服务、短进程和 fixture 为主。真实 Windows DPAPI fixture 已验证；真实账号授权、持续原画播放、显卡/HDR 输出、网络速度和完整云盘整理仍需用户环境验收。测试不操作生产服务替代这些验收。
2. 本地来源目前只读；不包含自动整理本地磁盘。远程 Jellyfin 不能使用客户端本地路径自动建库。
3. 云盘能挂载或列目录，不等于能执行整理。写操作只对已适配驱动和明确授权根目录开放；验证码、扫码和授权续期仍可能需要提供方交互。
4. 手动、启动时和定时模式启动的任务不同；目录存在某个脚本不代表它持续运行。没有来源时不会启动网盘缓存流程。
5. 分季评分只有核实到独立季身份且提供方有数据时才显示。缺评分、冷门人物、源站不可达或限流都可能需要手动处理，不承诺全库资料自动齐全。
6. `artwork.minimum_width/backdrop_width` 使用真实图片尺寸。提高门槛不会生成不存在的高清图；没有合格来源时保留可用旧图并等待后续任务。
7. 减少动态效果目前作用于影院海报拖拽、回弹和滚动虚化，不能解释为关闭所有平台动画。图片磁盘预算不包含视频与内存显示缓存。
8. 私有备份只含设置及加密凭据，不含 Jellyfin 数据库、媒体、图片缓存或完整运行历史。DPAPI 凭据不能直接跨用户/机器恢复；对外分享应使用脱敏配置导出。
9. 依赖版本表来自 Windows x64 CPython 3.13.3 隔离环境；未覆盖所有 Python 3.11+ 版本与架构。安装包仍需要独立媒体组件。

## 未实现或不属于本次范围

- 通用优先网卡绑定、校园网/外出网络自动切换、跨组件 HypoMux 自动路由及出口证明；相关未接入设置保持禁用。
- 原生 macOS/Linux/移动端发行；Kazumi 在线番剧融合和整站目录向 VidHub 同步；用户已取消的新增多版本选择功能。
- 独立 WebDAV 来源扫描和写整理；其他云盘驱动的自动整理适配。
- 资料语言的 source/item/season 覆盖：配置引擎有明确继承机制，但运行消费者未提供可靠祖先关系，当前界面只开放全局语言顺序。
- 整实例或媒体目录自动迁移、跨用户凭据迁移、通用自动更新器、全部外部服务的无人值守授权。
- 已有 Jellyfin 的用户权限接管、独立观看者自动创建、远程访问/公网入口自动开放。
- 全硬件实播验收与稳定版保证。本预览不代表所有真实环境已验收；发布状态以项目 GitHub Releases 为准。
