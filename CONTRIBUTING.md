# Contributing

Use an isolated instance and test media you may use. Do not develop against a
personal production server or commit its runtime directory. Start with the
commands in README, then run the relevant Python and browser tests.

New settings require schema validation, a real runtime consumer, a documented
effect time and a regression test. Disable unsupported controls instead of
pretending a saved value is effective. A source mutation needs explicit scoped
authorization, an inspectable plan and a resumable receipt.

Keep correctness rules separate from preferences: stable identity across
renames, source-aware cache invalidation, honest missing-metadata states,
preserving manual matches, and verification before removing empty directories.
Preserve original upstream license headers in vendor changes and document
which upstream behavior was modified. Third-party dependency upgrades should
include a clean install and playback smoke test.

Pull requests should describe the problem, resulting behavior and relevant
validation. Never include cookies, API keys, raw stream URLs or private logs.
